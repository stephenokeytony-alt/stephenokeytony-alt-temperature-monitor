Temperature Monitor and Alarm Checker

What it does

The Temperature Monitor and Alarm Checker is a Python program designed to monitor machine temperatures. It collects five temperature readings, calculates the highest, lowest and average temperatures, and warns the user when a reading exceeds the safe temperature limit of 60°C.

It also classifies the machine condition as Normal, Caution or Critical.

How to run it

1. Install Python 3 or use Pydroid 3 on Android.
2. Download or open "temperature_monitor.py".
3. Run the program.
4. Enter five temperature readings when prompted.

My own twist

I added a machine condition classification feature. It classifies the machine as Normal, Caution or Critical based on the highest temperature recorded.

What I learned

I learned how to use Python functions, loops, lists, conditional statements and error handling. I also learned how to calculate the average, highest and lowest values in a list.
